# Product Discount Calculator

A simple PHP app that calculates a product's discount price based on list price and discount percentage.

## Features
- Input form for product details
- Calculates discount amount and final price
- Formats currency and percentages
- Escapes output to prevent XSS

## Technologies
- PHP 8
- HTML5
- CSS3
- XAMPP (Apache)

## Setup
1. Place this folder inside XAMPP's `htdocs` directory.
2. Start Apache from the XAMPP control panel.
3. Visit `http://localhost/product-discount/index.php`.
